1) **В проектах открытый MD-файл не обновляется на лету, когда агент его правит.** Проверено: в «Заметках» живое обновление работает — там ничего не трогаем. Не работает именно в проекте: файл открыт в просмотрщике, агент его меняет, на экране старая версия, помогает только закрыть и открыть заново.
   - Причина найдена: перечитывание в просмотрщике уже реализовано — `FilePreview.tsx` и `NoteEditor.tsx` подписаны на `fs-changed` / `notes-changed` и вызывают `checkExternal()`, который перечитывает файл с диска и применяет изменения (`applyExternal`). Но эти события испускаются только из команд UI (`commands/files.rs`, `commands/notes.rs`) и из `undo` (`commands/undo.rs`). Инструменты агента — `fs_write`, `edit_file`, `apply_patch`, `notes_write` — событие не шлют вообще (в `agent/edit_tools.rs` и `agent/notes_tools.rs` эмитится только `versions-changed` / `trash-changed`). Поэтому правки агента просмотрщик не видит в принципе.
   - В «Заметках» (`NoteEditor.tsx`) тот же `checkExternal()` почему-то доходит до результата — вероятно, за счёт `index-changed`, который приходит после переиндексации заметок. В проекте такая подстраховка не срабатывает, поэтому правка агента просто не видна.
   - Чинить только в проектах: инструменты записи агента (`fs_write`, `edit_file`, `apply_patch`) должны испускать `fs-changed` с корректным `projectId` + `relPath` — тот же контракт, что у `commands/files.rs`. Просмотрщик менять не нужно, он уже слушает.
   - Второй пробел (по желанию): подписка живёт под условием `isTextual`, то есть для DOCX/PDF/прочих нетекстовых документов перечитывания нет вовсе.
   - Ожидаемое поведение: в проекте открытый файл сам перечитывается с диска, когда меняется внешним процессом (агент, другая программа, `bash`), без закрытия и переоткрытия. «Заметки» не трогаем — там уже работает.
