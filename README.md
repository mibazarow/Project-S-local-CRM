# Project S

Локальное десктопное приложение: **CRM + AI-агент + агентский харнес**. Один пользователь, всё работает на своей машине, без облака и серверной части. LLM подключается через любой OpenAI-совместимый API.

Коротко: папка проекта — это и есть проект. Внутри — файлы, задачи, доступы, заметки и чат с агентом, который видит контекст проекта. Отдельно есть «Харнес» — универсальный агент с доступом к компьютеру: файлы, терминал, браузер, SSH, планировщик, память и скиллы.

## Что умеет

- **Проекты/CRM** — список проектов, карточка клиента, файлы, доступы, импорт/экспорт, бэкапы.
- **Задачи** — канбан, приоритеты, дедлайны с временем, просрочка, таймер работы, чек-листы.
- **Файлы проекта** — дерево папок, список/плитка, предпросмотр, переименование, перемещение, drag-and-drop, импорт из Finder.
- **Заметки и файлы** — общий раздел для `.md` и любых файлов: изображения, PDF, текст, архивы; редактор заметок и превью.
- **AI-чат по проекту** — стриминг ответа, инструменты (задачи, файлы, поиск, интернет), подтверждения опасных действий, вложения.
- **Харнес** — сессии, расписания, память, скиллы, MCP-серверы, интернет, браузер, SSH, работа с процессами.
- **Поиск** — SQLite FTS5 + локальные эмбеддинги (ONNX Runtime, без Python).
- **Провайдеры LLM** — несколько профилей, активный выбирается в настройках; DeepSeek, Qwen и любые OpenAI-совместимые endpoint'ы.
- **Локальность** — данные, ключи и история лежат на машине пользователя; приложение не отправляет их в свой облачный сервис.

## Стек

| Слой | Технология |
|---|---|
| Оболочка | Tauri 2 |
| Бэкенд | Rust: агентный луп, SQLite, индексация, ONNX, CDP-браузер, планировщик |
| Фронтенд | React 19 + TypeScript + Vite |
| Стили | vanilla CSS, без Tailwind |
| БД | SQLite: метаданные, задачи, чаты, FTS5, векторный поиск |
| LLM | OpenAI-совместимый API (`/chat/completions` + tool calling) |

## Как устроено

```
React UI  ──Tauri IPC──  Rust core  ──  SQLite / файлы проекта
                              │
                              ├── агентный луп (tool calls → ответ)
                              ├── LLM-клиент (стриминг, провайдеры)
                              ├── поиск (FTS5 + эмбеддинги)
                              └── харнес (файлы, shell, браузер, SSH, MCP)
```

Рабочая директория по умолчанию — `~/Documents/PROJECT-S`:

```
PROJECT-S/
├── Projects/    # проекты; одна папка = один проект
├── Harness/     # рабочая территория харнеса
└── Settings/    # config, skills, .db, logs, backups
```

## Быстрый старт

Нужны macOS (v1), Node.js 20+, Rust stable и Xcode Command Line Tools.

```bash
npm install
npm run tauri dev     # приложение в dev-режиме
```

Проверки и сборка:

```bash
npm test              # фронтенд-тесты (vitest)
cargo test            # бэкенд-тесты (из src-tauri)
npm run build         # tsc + vite build
npm run app:build     # релизная сборка Tauri
npm run app:install   # сборка + установка в /Applications/Project-S.app
npm run app:update    # установить уже собранный бандл
```

## Статус

- v1 реализована и работает на macOS.
- Windows 11 и Linux — **в планах**, не реализованы; оценки и подводные камни — в `DOCS/WINDOWS-PORT.md` и `DOCS/LINUX-PORT.md`.

## Безопасность данных

- Приложение локальное: реальные данные проектов не должны попадать в репозиторий, моки, скриншоты и документацию.
- Примеры в документации и тестах — вымышленные (`example.ru`, `ИП Петров`, TEST-NET 192.0.2.0/24).
- API-ключи хранятся в локальных конфигах приложения, не в репозитории.
