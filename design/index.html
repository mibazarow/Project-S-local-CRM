Адрес API твоего провайдера, обычно заканчивается на /v1.

        
Хранится открыто в Settings/config/llm.json — папку можно переносить на другую машину.

        

          
          
Список подтянут с endpoint'а (/models). Если endpoint список не вернул — впиши название модели вручную, узнай у провайдера.

        

        
Подтянулось автоматически для выбранной модели. Если модель не сообщила — 100 000 по умолчанию; можно исправить руками.

        
      


      

        
Так агента будут звать в чатах проектов и харнеса.

        
Агент будет называть себя и обращаться к тебе именно так.

        

        
Выключено: опасные действия (терминал, запись вне папок проекта, браузер) агент делает только после твоего подтверждения. Включено: делает всё молча — на твоё усмотрение.

      


      

        
Файлы больше этого размера в индекс не попадают.

        
Из одного большого файла берётся не больше этого куска текста.

        
Папки и файлы, которые поиск по проекту никогда не увидит.

        
      


      

        
Скиллы — короткие инструкции для агента. Встроенные обновляются вместе с приложением, свои можно импортировать или создать.

        

        
      


      

        
MCP-серверы дают агенту внешние инструменты (например, доступ к Google Диску). Настраиваются в Settings/config/mcp.json.

        

        
      


      

        
Общая память всех чатов: агент запоминает важное и помнит это в любой новой сессии. Здесь можно смотреть, править и удалять записи.

        

        
      


      

        

        
Старые незакрытые разговоры харнеса чистятся сами; порог можно менять или выключить.

        

        
Нужно, чтобы расписания (напоминания, задачи по cron) работали, даже когда приложение не открыто.

        
Временные файлы агента удаляются сами, если старше этого срока.
