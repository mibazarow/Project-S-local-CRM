name: email-drafts
description: Draft business emails and replies from the given context (correspondence, notes, task). Use when the user asks to write, answer or rewrite an email or commercial message ("напиши письмо", "ответь клиенту").
---

Write business email the user can send as-is after one skim.

1. Gather context first: the thread being answered, the relationship with the recipient, the outcome the email should produce. If the thread sits in the app (chat, notes), read it before drafting.
2. Fixed skeleton:
   - **Тема** — one specific line ("Вопрос по срокам правок на сайте").
   - Обращение, short body (3–6 sentences max), sign-off.
   - One ask per email; concrete dates and numbers stated plainly.
3. Offer two tone variants when the situation is delicate (e.g. "нейтральный" and "помягче"), otherwise a single draft.
4. Russian business etiquette by default: «Добрый день», «С уважением», address by name when known. Match the language of the thread when it is not Russian.
5. Never invent facts — prices, terms, names. Leave a placeholder like `[дата]` and list the placeholders at the end for the user to fill.
